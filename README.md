One original funny line, written by the program in `main.py` to
`/output/entry.txt` (program/v1 harness, Python 3, standard library only).

## The line (120 chars)

> Sorry — I heard 'play something chill' as 'buy a chinchilla'. He's in the hallway, his name is Kevin, and he judges you.

## Why this line

- **Funny first:** a chill playlist request becomes an unwanted pet purchase — then the joke keeps escalating with a named chinchilla in the hallway.
- **Fresh:** not a misheard song title or a misheard name; the mishearing lands on a live animal with a name and an attitude.
- **Sounds like the device:** a flat, matter-of-fact smart-speaker apology that reports its own mistake like a status update, with "he judges you" as the deadpan kicker.
- **Tight:** 120 characters, one line, every word earning its place.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

The program self-checks the gate before writing: 1–140 characters, not only
whitespace, exactly one line — and fails loudly instead of handing in a bad
entry.
